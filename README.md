# Дашборд ДЗ / ДО

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Выполните:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. В браузере загрузите исходные `дз.xlsx` и `до.xlsx`.

## Что есть
- фильтры по типу, контрагенту, плательщику, дате счёта и договорной дате оплаты;
- KPI по сумме счетов, оплатам, остатку и просрочке;
- графики по типам, месяцам и контрагентам;
- детализация и выгрузка CSV/Excel.

## Важные допущения
В исходной выгрузке ДО отдельная сумма фактической оплаты не обнаружена. Сейчас сумма считается оплаченной при наличии даты оплаты клиента. Для точного учёта частичных оплат нужно добавить в исходный файл соответствующее поле.

## Особенности дат (учтены)
- Дата счёта берётся только из текста «Счет на оплату» в файле ДЗ.
- В файле ДО дата счёта не заполняется и не используется.
- «Дата оплаты по договору» берётся только из файла ДЗ. Одноимённое поле в ДО игнорируется как некорректное.
- Фильтры по этим двум датам применяются только к строкам ДЗ. Строки ДО сохраняются в результате без ограничения по этим датам.
