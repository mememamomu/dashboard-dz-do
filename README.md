# Дашборд ДЗ / ДО — постоянная ссылка для руководства

## Как это работает

1. **Вы** (администратор) открываете ссылку, вводите пароль, загружаете `дз.xlsx` и `до.xlsx`.
2. Смотрите расчёт, нажимаете **«Опубликовать для руководства»**.
3. **Начальник** открывает **ту же ссылку** — сразу видит опубликованные цифры, файлы загружать не нужно.

Снимок данных хранится в вашем **приватном** репозитории GitHub (файл `data/published.json`).

---

## Разовый setup (один раз)

### 1. Репозиторий GitHub
- Создайте **private** репозиторий, например `dashboard-dz-do`.
- Загрузите в него: `app.py`, `requirements.txt`, `README.md`.
- Создайте пустую папку `data` (можно добавить файл `data/.gitkeep`).

### 2. Personal Access Token
GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)**  
→ Generate new token:
- note: `streamlit-dashboard`
- scope: **`repo`** (полный доступ к private repo)
- скопируйте токен `ghp_...` (показывается один раз)

### 3. Streamlit Community Cloud
1. https://share.streamlit.io → войти через GitHub  
2. **New app** → выбрать репозиторий → Main file: `app.py` → Deploy  
3. В настройках приложения → **Secrets** вставьте:

```toml
admin_password = "придумайте_сложный_пароль"

[github]
token = "ghp_ваш_токен"
repo = "ваш_логин/dashboard-dz-do"
path = "data/published.json"
branch = "main"
```

4. Save. Приложение перезапустится.

### 4. Ссылка для начальства
После деплоя будет адрес вида:
`https://dashboard-dz-do-xxxxx.streamlit.app`

Её и отправляете руководству.  
Пароль им **не** нужен — они видят только опубликованный снимок.

---

## Ежедневная работа

1. Открываете ссылку → в боковой панели вводите **пароль администратора**.  
2. Загружаете актуальные `дз.xlsx` и `до.xlsx`.  
3. Проверяете цифры.  
4. Жмёте **«Опубликовать для руководства»**.  
5. Начальник обновляет страницу (F5) — видит новые данные.

---

## Локальный запуск (без публикации)

```bat
cd /d C:\скрипт\Дашборд
py -m streamlit run app.py
```

Без secrets режим публикации недоступен, но расчёт после загрузки файлов работает (включите «Режим загрузки и публикации» в сайдбаре).

Для локальной проверки публикации создайте файл  
`C:\скрипт\Дашборд\.streamlit\secrets.toml` с тем же содержимым, что в Cloud Secrets.

---

## Безопасность
- Репозиторий лучше держать **Private**.
- Токен GitHub храните только в Streamlit Secrets, не в коде.
- Пароль администратора не сообщайте руководству.
- В снимок попадает **сводка по контрагентам** (не полная детализация всех счетов). При необходимости можно расширить.
